# EmpathyIA Web Clipper

Extensão mínima e sem servidor para capturar a seleção ou o conteúdo principal de uma página como Markdown portável.

## Instalação de desenvolvimento

1. Abra `chrome://extensions` em Chrome, Edge, Brave ou outro navegador Chromium.
2. Ative **Modo do desenvolvedor**.
3. Escolha **Carregar sem compactação** e selecione esta pasta.
4. Use o botão da extensão; os arquivos serão gravados em `Downloads/EmpathyIA`.
5. No EmpathyIA, abra **Conhecimento → Importar e exportar** e importe essa pasta.

A extensão não usa servidor, não envia conteúdo pela rede e não executa código de terceiros.
